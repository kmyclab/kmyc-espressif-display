# KMYC-D101-DSI4L-800X1280-A1

KMYC 显示产品。供应商物料映射：CC10128007-31C，ILI9881C，31 Pin。
产品标识中的 DSI4L 沿用登记型号，原生方向 800×1280。

此 ESP-IDF 实现保留已验证来源的完整初始化表、
屏内 BIST 命令、71 MHz DPI 时钟、800 Mbps/lane 和两 lane 实验工作模式。
driver/panel_cc10128007_31c.h 内参数与初始化表是此模式的代码来源。
短文件名保留供应商料号用于追溯，不替代此目录的 KMYC 产品型号。

产品的四 lane 接口登记与当前两 lane 实验配置分开管理。
当前模式未获目视验收，不据此宣称任意板卡、四 lane 模式或量产兼容。
供电、复位、ACK 策略属于平台和 Adapter，不由产品编号决定。
供应商原始数据手册和工程文件不包含在此源码仓库中。
