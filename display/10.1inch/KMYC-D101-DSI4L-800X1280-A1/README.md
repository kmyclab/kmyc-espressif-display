# KMYC-D101-DSI4L-800X1280-A1

| 项目 | 参数 |
| --- | --- |
| 产品类型 | 显示屏 |
| 尺寸 | 10.1 英寸 |
| 分辨率 | 800×1280，竖屏原生方向 |
| 接口 | MIPI-DSI，产品登记为四通道 |
| 显示控制器 | ILI9881C |
| 供应商物料 | CC10128007-31C，31 Pin |

ESP-IDF 驱动包含面板初始化和内部 BIST。当前 Waveshare ESP32-P4-Pico 与
WT9932P4-TINY Adapter 使用两通道实验配置；这不会改变产品本身的四通道型号
身份，也不表示任意两通道主板都能直接使用。

已适配开发板和各项实机状态见
[兼容性状态表](../../../docs/hardware-support.md#兼容性状态表)。版本变化见
[版本记录](CHANGELOG.md)。
