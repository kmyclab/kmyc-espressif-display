# KMYC-DT101-DSI4L-800X1280-GT9271-OCA-G01-A1

10.1 英寸、800×1280 的显示触摸总成。

| 组成 | 型号 |
| --- | --- |
| 显示 | KMYC-D101-DSI4L-800X1280-A1 |
| 触摸 | KMYC-T101-CTP-I2C-GT9271-G01-A1 |
| 贴合 | OCA |
| 结构/版本 | G01 / A1 |

`assembly.yaml` 是供构建工具读取的组成关系。当前 Waveshare ESP32-P4-Pico
Adapter 使用两通道 DSI、GPIO8 SCL 和 GPIO7 SDA；其他开发板不能直接套用该
接线。已适配开发板和各项实机状态见
[兼容性状态表](../../../docs/hardware-support.md#兼容性状态表)。
