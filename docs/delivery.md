# 客户交付边界

目标交付物是选定 App 的独立 ESP-IDF 工程，main/ 属于该 App，
共享组件和硬件适配被收集到包内，默认配置对应客户的准确硬件组合。
交付包不得依赖私有工作区外部相对路径。

当前仓库源码按 GPL-2.0-only 发布；第三方 SDK 和组件继续适用各自许可证。
本轮尚未实现 export 命令。实现导出前仍需明确 SDK/依赖、完整产品和转接板
身份，并完成客户所需功能的硬件验证。不能把“编译通过”视作这些条件已满足。

未来导出验证至少覆盖：白名单文件收集、独立目录编译、锁定依赖、版本与
源码提交记录、第三方许可、排除 out/、日志、密码及内部标准/客户资料。
