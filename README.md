# KMYC Espressif Display

KMYC display software for the Espressif ecosystem.

## Repository status

This repository is being prepared for source publication. The initial commit
contains repository setup only: no firmware, supported hardware release, or
buildable application is published yet.

The intended structure is independent C applications, shared display components,
and chip-specific board support. Firmware will be added after redistribution
review; hardware validation status will be documented separately from build status.

## Clone

```sh
git clone https://github.com/kmyclab/kmyc-espressif-display.git
```

This repository is independent of the private engineering workspace. Future
published build instructions must not require private files or parent directories.
